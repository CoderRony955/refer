**refer** is a CLI tool for sharing local project folders quickly using downloadable links and simple HTML share pages.

## Key Features
- **Direct Path Sharing**: Share one folder with `refer -path` without extra setup
- **Multi-folder Sharing**: Share multiple folders with one message using `referwith -message -paths`
- **Template Output**: Use `referwith -template` for cleaner share pages
- **Simple Command Flow**: Focused commands for fast day-to-day sharing
