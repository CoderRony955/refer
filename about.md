**refer** is a tool that designed to help you quickly access and manage your personal reference library. Whether you're storing code snippets, documentation links, or important information, Refer makes it easy to organize, retrieve, and share references.

## Key Features

- **Quick Access**: Retrieve references instantly with simple commands
- **Local Storage**: Manage references in your personal database
- **Flexible Retrieval**: Access references either through the local database or directly from file paths
- **Organized Categories**: Keep your references organized with basic commands, management tools, and referral commands
